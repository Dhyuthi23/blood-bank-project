\# 🩸 Blood Bank Management System



\## 📌 Description

This project is a web-based blood bank system developed using PHP and MySQL.



\## 🚀 Features

\- Add Donor Details

\- Request Blood

\- View Blood Stock



\## 🛠️ Technologies Used

\- PHP

\- MySQL

\- HTML, CSS

\- XAMPP



\## ▶️ How to Run

1\. Start XAMPP

2\. Open browser

3\. Go to http://localhost/blood\_bank/
